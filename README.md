# Discord ENTAKU Overlay

Discordのボイスチャット（VC）参加者を、討論番組のような3Dのテーブルに並べてOBSに映すローカルアプリです。話している人に合わせてカメラが切り替わり、発話中はアイコンの周りが緑色に光ります。

**まずはDiscordに接続せず、デモで試せます。** Windows版はBunやNode.jsのインストール不要です。

> **開発中（v0.1.0-rc.15）**：リリース候補です。Discordの認可やOBS本体との組み合わせは環境によって動作が異なり、長時間運転も十分に検証できていません。最初は配信せずプレビューで確認してください。

## どんなことができる？

- VCの入退室・発話に合わせて、司会席付きのカプセル型テーブルに参加者を表示します。人が抜けても机をすぐには縮めず、予約された席へ復帰できます。
- 1人の肩越し、2人、全景、離れた2人の左右分割を自動で選びます。Dockから特定の人を手動で撮ることもできます。
- Discordアイコンを、PNG／静止WebPのカスタムアバターへ置き換えられます。
- 静的な3DGSキャラクターを取り込み、2D画像と混在させられます。顔位置・向き・描画量を調整し、キャラクターをZIPで持ち運べます。[利用手順と検証範囲](docs/gaussian-avatars.md)を参照してください。
- GLB／GLTFのスタジオ背景、木目の机、名札、露出・影・画質・ポストエフェクトを調整できます。
- 操作ページの「VC-CHAT」で、参加中のサーバーVCのテキスト投稿を読み取って表示します。OBSの映像には出さず、投稿・送信もできません。

## 1. Windows版を入手する

必要なのはWindows x64のPCです。実際のDiscord通話と連携するときは、同じPCでDiscordデスクトップアプリを起動してください。OBSは配信画面を使う段階で必要です。

現在は正式なインストーラーではなく、GitHub Actionsの開発用ZIPを配布しています。

1. [GitHub ActionsのCI一覧](https://github.com/zkamiyama/Discord-ENTAKU-Overlay/actions/workflows/ci.yml)を開き、成功（緑のチェック）の実行を選びます。
2. 実行ページ下部の Artifacts から `entaku-windows-development` をダウンロードします。GitHubへのサインインが必要な場合があります。
3. ダウンロードしたZIPを開き、中の `Discord-ENTAKU-Overlay-...-windows-x64.zip` をさらに展開します（ZIPは二重です）。
4. 展開先に `ENTAKU-Overlay.exe`、`Start-Demo.cmd`、`Start-Live.cmd` があれば準備完了です。

Artifactsは14日間だけ保存されます。見つからない場合は、別の成功した実行を確認してください。exeは未署名です。OSの警告が出たときは、配布元とファイルを確認し、保護設定を無効にせずに判断してください。

## 2. まずはデモを試す（Discord不要）

1. 展開したフォルダーの `Start-Demo.cmd` をダブルクリックします。
2. 操作ページ（Dock）がブラウザで開きます。開かない場合はコンソールに表示される `Dock:` のURLを開いてください。
3. Dockの参加者一覧でマイクのアイコンを押すと、デモの発話をON／OFFできます。
4. [映像ページ（Overlay）](http://127.0.0.1:31337/overlay)を開くと、テーブルとカメラの切り替えを確認できます。

発話開始から既定で実発話1.5秒で撮影対象になります。発話が止まったあとは2.5秒の終了確認と5秒の切替猶予があります。手動で「この人を撮る」を選んだ場合は、通常10秒で自動撮影に戻ります。

終了するときは起動したコンソールでCtrl+Cを押してください。デモと実通話を同時に起動しないでください。

## 3. Discordの実際のVCと接続する

1. デモを終了し、Discordデスクトップアプリを起動してサーバーのボイスチャンネルに参加します。
2. `Start-Live.cmd` を起動します。画面に出る注意事項を読み、互換認証を使う場合のみ Y を選びます。
3. Discordに認可画面が表示された場合は、権限の内容を確認して許可します。
4. Dockに参加者が並んだら接続完了です。VC-CHATはアプリ起動後の投稿を表示します。以前の投稿を自動取得・表示する設定ではありません。

**認証について：** 現状はDiscordのStreamKitアプリ識別子を使う互換方式です。ENTAKUがDiscordに独立したアプリとして承認された方式ではありません。プログラムの要求スコープは`rpc`と`rpc.voice.read`ですが、Discordが実際に付与した権限や認可画面も確認してください。参加者・発話状態に加え、利用可能な場合はVC内蔵チャットの本文を読み取ります。**音声データの受信・録音・文字起こし・メッセージ送信はしません。** この互換経路の継続利用や公開配布条件は未確認です。

## 4. OBSに表示する

ENTAKUを起動したまま、OBSで2つのページを登録します。

| OBSで追加するもの | URLと用途 |
|---|---|
| ソース → ブラウザ | `http://127.0.0.1:31337/overlay` — 配信・録画に映る3Dシーン。幅1920／高さ1080を推奨 |
| ドック → カスタムブラウザドック | `http://127.0.0.1:31337/dock` — 席・カメラ・スタジオ・画質を操作する画面 |

操作ページ自体は配信映像に映りません。OBSのメニュー名はバージョンや言語設定で多少異なる場合があります。

この2つのURLは同じPCだけで使います。末尾にアクセスキー（`#key=...`）を付ける必要はありません。ポートを変えた場合は両方のURLを変更してください。

## 5. よく使う操作

| したいこと | Dockでの操作 |
|---|---|
| 特定の人を大きく撮る | 参加者のカメラアイコン「この人を撮る」 |
| カメラを自動／手動固定にする | 「自動 ON／OFF」。自動ONなら手動撮影後に自動復帰 |
| 司会者・共同司会者を選ぶ | 参加者の `…` →「司会に指定」「共同司会に追加」 |
| 席を移動・入れ替える | 参加者の `…` →「席移動」 |
| カスタム画像を使う | 参加者の `…` →「アバターを調整」 |
| 背景を変える | 「スタジオ」→「GLB/GLTFを読み込む」または「フォルダを読み込む」 |
| 見た目・負荷を調整する | 「画質」「露出・照明」「ポストエフェクト」 |
| 設定を保存する | 最上段のプリセット一覧 →「現在の状態を新規プリセットに…」 |

プリセットは`data/presets/*.json`に保存されます。カスタム画像や背景の実ファイルは`data/assets/`にあるため、別PCへ移すときは`data/`をフォルダーごとコピーしてください。チャット本文はメモリ内に最大100件まで保持し、ファイルには保存しません。

## 6. 困ったとき

| 状況 | 確認すること |
|---|---|
| DockやOverlayが開かない | 起動したコンソールが開いているか確認し、そこに表示されたURLを開く |
| `PORT_IN_USE` | 以前起動したENTAKUを終了。別ポートで起動する場合はOBSのURLも更新 |
| Discordの参加者が表示されない | 同じPCのDiscordデスクトップアプリ、サーバーVCへの参加、認可画面、Dockの接続状態を確認 |
| 映像が重い | Dockの「画質」で「軽量」を選択し、SSR・GTAO・影の灯数や描画解像度を下げる |
| GLBが明るすぎる／暗すぎる | 「露出・照明」で自動露出とEV補正を確認 |
| `DATA_PATH_PERMISSION_DENIED` | 書き込み可能なフォルダーに展開する。`--data-dir`で保存先を指定する方法もあります |

設定を消さずに調べるには `ENTAKU-Overlay.exe --safe-mode`、認可せず環境だけ確認するには `ENTAKU-Overlay.exe --doctor` を使えます。詳細は[起動とOBSへの登録](docs/getting-started.md)と[検証状況](docs/implementation-status.md)を参照してください。

**更新するときはアプリを終了し、`data/`をバックアップ**してから新しいexeに入れ替え、OBSのブラウザソースとDockを再読み込みしてください。

## Bunでソースから動かす（開発者向け）

[Bun 1.4.4](https://bun.sh/) とGitを使用します。通常利用だけなら、この作業は不要です。

```powershell
git clone https://github.com/zkamiyama/Discord-ENTAKU-Overlay.git
cd Discord-ENTAKU-Overlay
bun install --frozen-lockfile

# デモ：Web素材のビルド込み
bun run dev
```

実VCに接続する場合はデモを止め、Web素材を準備してから、上の互換認証に同意する場合だけ次を実行します。

```powershell
bun run build:web
bun run start --live --compat-auth --accept-streamkit-compat
```

テストは `bun run check`（型チェック・単体／結合）、`bun run test:e2e`（Playwright／Chromiumが必要）です。実装と改善候補は[リファクタリング監査](docs/refactoring-audit-2026-11-10.md)、シーン素材は[スタジオの説明](docs/studio.md)、各RCの変更履歴は[docs](docs/)から確認できます。

## 取り扱いとライセンス

ENTAKUは`127.0.0.1`で動作するローカルアプリです。ローカルの別プロセス向け認証は設けていません。保存した`data/`にはDiscord IDなどが含まれるため、共有・公開前に内容を確認してください。現状は未署名のリリース候補で、実Discord・OBSでの長時間受け入れ試験は完了していません。
