# ADR-0017: 無音2.5秒で発話終了を確認してから構図変更を待つ

- 状態: 採用
- 日付: 2026-11-09
- 対象: RC.11、発話ターン、カメラ判断、Dockの表示

## 決定

DiscordのSTOPを、そのまま会話上の終了と扱わない。最後のSTOPから無音が2.5秒続くまでは終了確認中とする。この間にSTARTが来れば同じ発話ターンを再開し、既に満たした資格判定と実発話時間を引き継ぐ。無音がちょうど2.5秒続いた時点で終了を確定する。

終了を理由とする構図縮小や無音によるワイド復帰の5秒猶予は、終了が確定してから数える。他の話者の開始がなければ、最後のSTOPから最短7.5秒となる。確認中でも5秒猶予中でも、再発話したら終了待ちを取り消す。終了確認後の再発話は新しい発話ターンとして扱うが、残っている構図を即座に捨てない。

新しい話者へ移る開始判定は、実発話2.5秒のままとする。手動操作、通信断、机の再配置、参加者の退出には、それぞれ既存の優先規則を使う。退出は無音とは区別する。

## 音声信号と撮影状態を分ける

発話グローと生のSTART/STOP区間は変更しない。直近10秒の発話量、同時発話時間、発話交代数にも無音を足さない。カメラ用に発話ターンを保持する状態を追加し、既存の250msの信号断片の結合とは分離する。

短い相槌を、無音待機だけで長い発話へ昇格させない。重複したSTOPは期限を延ばさず、不明状態・接続断では保持を取り消す。

3人以上の全景から絞る場合も同じ確認を使う。複数人が異なる時刻に止まったときは、構図から外れる人のうち最後の終了確認を基準に5秒待つ。

## 表示と検証

Dockは最初の2.5秒を「終了確認」、その後を「切替まで」と分けて表示する。境界時刻、再開、短い相槌、重複STOP、不明状態、10秒間の正確な発話量、2人構図と左右分割、3人目への引き継ぎ、手動優先を試験する。発話の意味や感情を認識する変更ではなく、指定された時間条件による撮影規則である。
