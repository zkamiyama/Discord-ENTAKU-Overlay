# ADR-0016: JSONプリセット、席移動、スタジオの直接読み込み

- 日付: 2026-11-09
- 状態: 採用。実装・試験後に配布する。

## 席と名札

退出し、予約も解放した人はDock一覧から除く。画像設定は消さず、Discordで再参加した場合は再び表示する。席移動は物理席を選び、使用中なら相手と入れ替える。司会という役割は移動先の席に属する。空の司会席を保持するため、セッションにmoderatorSlotsを追加し、旧版はmoderatorIdsから移行する。移動だけでは机の長さやほかの席を変えない。

名札は天板の内縁へ寄せる。共同司会の席角度を拡げ、名札の設置面が重ならないようにする。描画とカメラのフレーム判定には同じ位置関数を使う。Three.jsのBox2を使って名札の余白と重なりを試験する。

## スタジオ

別ウィンドウのシーン編集UIを廃止し、DockにGLB・GLTFと関連ファイル・ZIPの選択を置く。読み込みには既存のGLTFLoader・LoadingManager・公式デコーダーを使い、モデルの解釈を自作しない。検証に失敗した場合は現在の背景を変更しない。選択した素材は背景を置き換え、色・画質・カメラの設定は保持する。旧シーンのプリミティブや詳細な配置値は互換性のためJSONで扱える。

## プリセット

タイトル表示をプリセットプルダウンへ置き換える。一覧はdata/presets直下のJSONファイルから取得し、末尾に区切りを入れて「現在の状態を新規プリセットに…」を置く。ファイル名ダイアログで保存し、同名の既存ファイルは上書きしない。書き込み中のファイルが一覧へ出ないよう、一時ファイルから完成後に公開する。

プリセットにはスタジオ、机の基準位置、カメラ、露出、画質、ポストエフェクト、画像調整、席割当、司会席、自動ON/OFF、外観を保存する。画像やGLBの本体はassets内の既存IDを参照する。発話イベント、接続先、認可情報、切替カウントダウンは保存しない。読み込みは値と素材を検証してから適用し、実際の在席者はDiscordの状態を優先する。別の通話チャンネルへ接続する操作は行わない。

## 既存機能の確認

Three.js r187のGLTFLoader、LoadingManager.setURLModifier、Box2.setFromPoints/intersectsBoxを確認した。素材検証・保存と役割付き席の入れ替えはアプリ側の処理である。
