# ADR-0010: 司会側を固定した机の伸長と、人物の色を変えない画質設定

- 状態: 採用
- 対象: RC.5の配置、卓上小物、描画とDock
- 変更元: ADR-0007の配置、ADR-0009の露出

## 司会側を固定する

最初の在席配置の直線長をセッションの`growthAnchorLength`へ保存する。長さLと保存値Aから机中心の移動量を`(L-A)/2`とし、机と席を+Zへ移す。奥側の円弧中心は`offsetZ-L/2=-A/2`となり、増席時も動かない。机の伸長アニメーション、席、小物、全景カメラ、標準セットと編集プレビューで同じ移動量を使う。

既存セッションには、増席を適用する前の配置を基準として保存する。旧版で合わせたカスタムGLBの位置を、更新直後に勝手に変えない。退出では机を縮めず、保持したアンカーと席予約を復元する。司会人数の変更や明示的なセッションリセットによる再配置は別の操作である。

## 画質は公式機能を組み合わせる

Three.js 0.187.0の実装を確認した。影は`PCFShadowMap`、接地感は`GTAOPass`、画面内反射は`SSRPass`、輪郭補正は`FXAAPass`、トーンマッピングとsRGB出力は`OutputPass`を使う。`PCFSoftShadowMap`を新たに導入しない。独自のAOや反射探索器は作らない。

既定は自動露出とソフトシャドウである。AO、SSR、FXAAは個別に有効化する。影の解像度、影を作る灯数、画面効果の解像度と強さをDockに用意する。SSR対象は天板と滑らかな材質に限定し、すべての壁を鏡面として扱わない。画質変更だけで進行中のショットや席予約をリセットしない。

このSSRは基本的なスクリーンスペース反射であり、AMD FidelityFX SSSRではない。画面外の物体は反射できない。SSGIはこの版に含めない。既存の`realism-effects`にはSSGIがあるが、独自の描画パイプラインと透過・材質対応を含む検証が別途必要なため、未検証のスイッチを公開しない。

## 人物と文字を後処理から分離する

HDRのワールド描画、反射、AO、AgXとsRGB変換を先に行う。アバター、Discordアイコン、発話グロー、名札の印刷面は後から描画し、これらのRGBに露出や画面効果を適用しない。

色だけを合成すると人物が机を突き抜ける。そこでワールドの深度と透明度を保持し、最終出力へ深度を復元してから人物を描く。この合成だけはアプリ固有の処理とする。人物はAO・SSRの生成にも含めないため、人物を映す鏡面反射や板状の人物影はこの版の範囲外である。

対応する浮動小数点ターゲットがない、または効果の処理が失敗した場合は直接描画へ戻す。Dockにその状態を表示し、未対応の効果が有効だと表示しない。不要になったターゲットとパスはdisposeする。

## 卓上を修正する

生成するモニターとコップは削除する。マイクは台座、曲がったネック、カプセルとグリルを持つ形にする。名札は台形断面の立体とし、前後に鏡像でない印刷面を置く。文字は太字で横幅を使う。指定の白地・青文字を既定とし、参考写真にある青地・白文字も選べるようにする。天板は木目、微細な凹凸と薄いクリアコートを持つ。

設置面と撮影範囲の寸法は共通定義を使う。名札の四隅とマイク台座が、1〜32席、司会1〜2名で天板の木調部分の内側に入ることを検証する。

## 検証の区別

自動テストは後方固定、保存復元、画質設定、色の不変性、深度遮蔽、透明背景、リソース解放を対象とする。ブラウザ試験と実OBSでのGPU性能は別に記録する。実写と同じ照明結果や、すべてのPCで1080p60を保証する変更ではない。
