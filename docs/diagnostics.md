# 診断と発話イベント再生

Dockには接続状態、カメラの判断理由、最短維持時間の残り、話者の実発話時間を表示します。「診断とイベント記録」では映像ページの状態、フレーム間隔、draw calls、三角形数を確認できます。フレーム間隔はブラウザの計測値であり、GPU処理時間やOBSの出力fpsそのものではありません。

## 性能計測（PR #6）

PR #6の改修ブランチでは診断APIに次の項目を追加した。フレームとCPUの標本は最大240件、GPUの標本は最大32件。

| JSONの項目 | 内容 |
|---|---|
| `frameSamples`、`frameP50Ms`、`frameP95Ms`、`frameP99Ms` | 描画フレーム間隔の標本数とパーセンタイル |
| `prepareP95Ms` | CPUによるシーン・カメラ等の準備時間のP95 |
| `submitP95Ms` | CPUによる描画命令送信時間のP95。GPU時間とは異なる |
| `gpuSamples`、`gpuP95Ms` | WebGL2の非同期GPUタイマーの標本数とP95。未対応または標本なしでは省略 |

GPU時間はProgramRendererの処理全体に対する計測で、パス別のGPU時間やGPUメモリ使用量ではない。フレームの例外は `RENDER_FAILED` で報告する。実装と検証範囲は[アーキテクチャの現状](architecture-status.md)を参照する。

## 読み取り方

| 状態 | 内容 |
|---|---|
| `STATE_WAITING` | 最初の有効な全状態を待っています。カメラを未確定のまま描画しません |
| `STATE_STALE` | 接続または差分同期が途切れています。最後の確定状態を表示し、再同期を待ちます |
| `READY` | 有効な状態を受信し、スタジオの読み込みが完了しています |
| `STUDIO_LOADING` | 新しいスタジオ候補を読み込んでいます |
| `STUDIO_LOAD_FAILED` | スタジオ候補の読み込みに失敗しました。完成済みのスタジオは保持します |
| `STUDIO_CAPACITY_OVERFLOW` | 机の拡張が背景の想定範囲を超えています |
| `CAMERA_SAFE_FALLBACK` | 有効な撮影位置がないため背景を隠しています |
| `CUSTOM_AVATAR_UNAVAILABLE` | 人物素材を読み込めません |
| `WEBGL_CONTEXT_LOST` | 描画コンテキストが失われています |
| `RENDER_FAILED` | 描画フレームの処理で例外が発生しました |

スタジオの読み込みと画質処理は、同じ設定で失敗した場合に500ms、2,000msの間隔で最大2回再試行します。再試行も失敗したら設定を変更するか、映像ページを再読み込みして復旧を確認してください。スタジオ候補を待つ間は完成済みのスタジオとカメラの組合せを表示し、参加者と発話の更新を続けます。スタジオを解除しても円卓・人物・席予約は保持します。接続が不明なときは発話をunknownとして扱い、固定時間が過ぎたという理由だけで発話終了を捏造しません。

## 記録

「発話イベントを記録」は音声の録音ではありません。参加者の増減と発話START/STOPをメモリに記録します。名前、チャンネル名、Discord IDを仮名へ置き換えます。トークン、画像URLを記録しません。停止後に「再生用JSONLを書き出す」を押します。書き出したファイルには会話の時刻パターンと人数が残るため、公開範囲は利用者が判断してください。

記録は入力イベントの再生用です。素材、カスタム画像、スタジオ、手動カメラ操作を含む完全な番組プロジェクトの記録ではありません。記録上限に達した場合は停止し、Dockに表示します。アプリ終了時にはメモリ内の未保存記録は失われます。

## 再生

```powershell
.\ENTAKU-Overlay.exe --replay .\entaku-events.jsonl
```

再生モードのDockには一時停止・再生速度・シークを表示します。前の時刻へのシークはドメイン状態を作り直してイベントを再適用します。再生データからDiscordへ接続することはありません。実際の通話の設定・席保存も変更しません。

## 問題報告

診断JSONはローカルDockからキーなしで出力できます。状態・件数・固定の理由コードを含め、利用者名、Discord ID、任意の上流エラー本文は含めません。公開Issueにはアプリ版、OS、OBS版、起動モード、再現手順と診断JSONを添付してください。コンソール全体や個人情報は公開しないでください。
