# 診断と発話イベント再生

Dockには接続状態、カメラの判断理由、最短維持時間の残り、話者の実発話時間を表示します。「診断とイベント記録」では映像ページの状態、フレーム間隔、draw calls、三角形数を確認できます。フレーム間隔はブラウザの計測値であり、GPU処理時間やOBSの出力fpsそのものではありません。

## 読み取り方

`READY`はスタジオ読み込みが完了した状態です。`STUDIO_LOADING`は処理中、`STUDIO_LOAD_FAILED`は素材を読み込めない状態です。`STUDIO_CAPACITY_OVERFLOW`は机の拡張が背景の想定範囲を超えています。`CAMERA_SAFE_FALLBACK`は有効な撮影位置がないため背景を隠した状態です。`CUSTOM_AVATAR_UNAVAILABLE`は人物画像の読込失敗、`WEBGL_CONTEXT_LOST`は描画コンテキストの喪失です。

素材のエラーは、その設定を編集し直すか映像ページを再読み込みして復旧を確認します。スタジオを解除しても円卓・人物・席予約は保持します。接続が不明なときは発話をunknownとして扱い、固定時間が過ぎたという理由だけで発話終了を捏造しません。

## 記録

「発話イベントを記録」は音声の録音ではありません。参加者の増減と発話START/STOPをメモリに記録します。名前、チャンネル名、Discord IDを仮名へ置き換えます。トークン、画像URLを記録しません。停止後に「再生用JSONLを書き出す」を押します。書き出したファイルには会話の時刻パターンと人数が残るため、公開範囲は利用者が判断してください。

記録は入力イベントの再生用です。素材、カスタム画像、スタジオ、手動カメラ操作を含む完全な番組プロジェクトの記録ではありません。記録上限に達した場合は停止し、Dockに表示します。アプリ終了時にはメモリ内の未保存記録は失われます。

## 再生

```powershell
.\ENTAKU-Overlay.exe --replay .\entaku-events.jsonl
```

再生モードのDockには、一時停止・再生速度・シークを表示します。前の時刻へのシークはドメイン状態を作り直してイベントを再適用します。再生データからDiscordへ接続することはありません。実際の通話の設定・席保存も変更しません。

## 問題報告

診断JSONはローカルDockからキーなしで出力できます。状態・件数・固定の理由コードを含め、利用者名、Discord ID、任意の上流エラー本文は含めません。公開Issueには、アプリ版、OS、OBS版、起動モード、再現手順と診断JSONを添付してください。コンソール全体や個人情報は公開しないでください。
