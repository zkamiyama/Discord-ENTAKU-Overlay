# GLB/GLTFの3Dメッシュアバターを発話で光らせる

## 使い方

スタジオに読み込んだGLB/GLTFモデルをDiscordの参加者に結び付けると、その人物の発話に合わせてモデルの外周に緑色のグローを表示します。3DGSと同じ**画面上の投影サイズを基準にした発光幅**を使います。円形リングは出しません。

1. Dockの「スタジオ」からGLB/GLTFモデル（必要なテクスチャは同時選択かフォルダーで）を取り込みます。
2. 「3Dメッシュアバターの発話グロー」を開き、対象の「3Dモデル」を選びます。
3. 「対応する参加者」を選んで「関連付けを保存」を押します。
4. 発話中は輪郭が光り、発話が止まると消灯します。モデルと参加者の対応はスタジオ設定に保存され、プリセットにも入ります。
5. 解除する場合は参加者を「関連付けなし」にして保存します。

リンク中のモデルは、参加者の2D画像や3DGSの身体表示を置き換えます。名札はそのまま残ります。本人が退出・不在になればモデルは非表示になり、復帰すれば再表示されます。接続断やstaleでは既存の発話フェードを継承し、GLB本体の透明度も在席状態に合わせます。元のGLB素材・マテリアルを保存時に改変しません。

**位置と向きはスタジオモデルに保存されたままです。** この版では参加者の席へ自動で移動させません。モデルをアバターとして使う際は、スタジオのモデル設定（JSONの `transform`）や元のGLBで位置・倍率を合わせてください。部屋全体のGLBを参加者と関連付けると、部屋全体が発話表示に切り替わるため、人物のみのモデルを使ってください。Studioの既存のモデルインポート経路を再利用しており、アバターエディターの新しい「GLB」形式ではありません。

## 描画方式

3DGSの発話グローと同じ`projectedObjectHeightPixels`と`speechScreenGlowRadius`を使います。カメラごとにモデルの形状を画面へ投影し、発光層の幅をその縦幅の6%から計算します。基本の幅を描画先の高さの約1.2〜6.5%（最小4px、最大72px）へ制限し、既存の発話グロー倍率1〜8を適用します。左右分割では各画面のカメラとレンダーターゲットの画素数から計算するため、広角・アップ・左右分割に追従します。

メッシュにはThree.jsの`MeshBasicMaterial`を使った裏面シェルを2層追加します。`onBeforeCompile`で公式の頂点投影だけを拡張し、スクリーン上の法線方向へグロー幅分だけ頂点をずらします。元のジオメトリ・スキニング・インスタンスデータを共有し、元GLBのマテリアルやテクスチャは変更しません。2層の透明度で輪郭に広がりを付けています。

追加のシェルはディスプレイレイヤーで描きます。したがって元メッシュの物理的な影やSSRの深度・法線を変更せず、机など手前の物体の深度テストを受けます。発話していない時は追加シェルを非表示にします。姿勢変化、ズーム、カメラCUT、SPLITでも同じ計算です。

公式の`OutlinePass`も検討しましたが、全画面のマスク・輪郭用レンダーターゲットと専用の合成処理が必要です。既存の品質設定と独立した少数メッシュの輪郭を、追加レンダーターゲットなしで描くため、Threeの標準メッシュシェーダーに最小限の投影拡張を加えました。選定理由は[ADR 0025](adr/0025-mesh-avatar-speech.md)を参照してください。

## 制約と確認

- 閉じた立体メッシュの輪郭に適した方式です。薄い板ポリゴン・欠けた面・反転法線では外周の一部が欠ける場合があります。
- テクスチャのアルファを使う薄い髪や半透明な服は、元素材と同じ完全なマスク表現にはなりません。実素材ごとに確認してください。
- シェルは2つずつ元メッシュへ追加されます。多数のMeshを持つGLBでは描画コストが増えます。元のジオメトリは複製しません。
- 発光は最終的な表示色への加算です。メッシュ本体の物理的な発光や、発話グローそのもののSSRへの反射を生成する機能ではありません。
- スタジオのモデルは静的な配置のままです。骨格アニメーションは元モデルのスキニングを共有しますが、アニメーションクリップを自動再生する機能は追加していません。
- 実Windows／OBS／長時間配信での負荷検証は別途必要です。

検証では、GLB相当のメッシュ（頭はSkinnedMesh、胴体・腕・脚はMesh）を実WebGLで描画し、発話ON/OFF、発光倍率、遮蔽物、分割、後処理を比較します。単体では参加者IDの検証、素材・マテリアルの寿命、SkinnedMesh・InstancedMesh、投影サイズ計算、スタジオ設定の保存を検査します。

```sh
bun run check
bun run build:web
bunx playwright test e2e/mesh-speech-glow.spec.ts e2e/studio-assets.spec.ts --workers=1
```
