# 開発・検証状況

更新日: 2026-11-06。対象: 0.1.0-rc.1。実装の完了と、利用環境での受け入れを区別する。

## 実装済み

IPCの取得・明示同意の互換認証、参加者の正規化、再接続・再購読、最大同時人数と予約席の分離、セッション保存、自動カメラ、名前プレート、可変円卓、画像アバター、Dock操作を実装した。

今回、カスタム画像の独立した背面、撮影範囲、3Dプレビュー、画像幅に応じた席間隔、Workerでの距離マップ生成を追加した。スタジオはGLTFLoaderと公式デコーダーを使い、相対リソースを含むGLTF・GLB・ZIPを取り込む。床・箱・ライト、モデルの配置、円卓基準点、障害物領域、退避ワイドも編集できる。

診断、匿名化した発話イベントの記録・書き出し、再生・速度・シークを実装した。Windows配布ZIPには単独exe、明示同意を求めるライブ起動スクリプト、説明、同梱ソース、ライセンス、コミット情報とハッシュ一覧を含める。

## 確認済みの試験

ローカルの型検査と単体・結合テスト88件が成功した。模擬IPCでの分割フレーム、nonce、購読、切断、タイムアウトを含む。席の保存復元、画像・相対パス・ZIP展開上限、編集競合と保存失敗、背面と撮影範囲、カメラ経路、匿名化、再生の巻き戻しも試験した。

ChromiumのE2Eは12件が成功した。Dockから映像の変化、画像の編集・保存復元、狭い画面、スタジオの相対テクスチャ、素材不足、障害物で囲まれた場合の退避、イベント記録と再生操作を確認した。独立した背面画像が減光されない不具合を実描画で再現し、修正後は正面・背面の画素比較が通った。

GPU資源はThree.jsのdisposeを用い、MeshだけでなくLine、Points、InstancedMesh、Skeleton、共有テクスチャも解放する。片方の画像読込が失敗した際に、成功した画像が残る経路も修正しテストした。

Windows/LinuxのCIは型検査、単体・結合テスト、単独実行ファイル生成、PATHが空の一時フォルダーでの起動試験を行う。ブラウザジョブではE2Eを行う。配布対象コミットの成否はGitHub Actionsの対応する実行記録を参照する。別のコミットの成功を配布版の成功とみなさない。

## 安定版に進めるための外部確認

実Discord通話での認可、2人以上の入退室・発話・Discord再起動と再購読は未検証である。OBS本体でのドック・ソースのライフサイクル、日本語表示、実時間2時間の運転、16人1080p60の性能測定も未検証である。署名と互換認証経路の公開配布条件の確認は未実施である。

仮想時計による2時間相当の状態遷移テストは、実時間2時間のGPU・ネットワーク・OBS試験を代替しない。これらが残る間はRCと表記し、実機検証済みの安定版とはしない。

## 初版の範囲

スタジオは静的背景で、障害物は明示的なBox3領域を使う。任意モデルの全ポリゴンから撮影経路を自動生成しない。HTTPSの素材取得、背景アニメーション、素材を含むプロジェクトZIPのGUI書き出し、手動カメラ操作込みの完全な番組再現は初版に含めない。

カメラ判断の時間設定は`src/domain/defaults.ts`の固定値である。可変幅は全席の間隔を拡げる方式で、席ごとの密詰めではない。画面は16:9を基準とする。これらを未確認の機能として表示・案内しない。
