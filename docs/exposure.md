# 露出と照明

RC.4では自動露出が既定です。旧シーンに露出設定がない場合も有効になります。操作はDockの「露出・照明」にまとめています。

## 調整する

通常は「自動露出」を有効にしたまま、明るさを「補正（EV）」で調整してください。+1 EVは露出倍率を2倍、-1 EVは半分にします。「現在値で固定」は、接続中の映像ページが報告した倍率を保存して手動へ切り替えます。固定前にOverlayを開いてください。

自動露出を外すと「手動倍率」を指定できます。「自動に戻す」は、EV補正0・自動測光・照明の自動選択へ戻します。変更はscene.jsonに保存します。露出だけの変更ではカメラや席をリセットせず、GLBも再ロードしません。

## どこに影響するか

スタジオ、机、卓上の立体物は露出補正を受けます。人物画像、Discordアイコン、発話グロー、名前プレートは補正を受けません。これらは測光対象からも除外しています。人物と机は同じ深度テストを使うので、机の下に隠れた画像が前面へ出ることはありません。

AgXとsRGB出力を使用します。自動露出は64×36の線形HDR画像を測り、明るすぎる部分と暗すぎる部分を除いて計算します。初回と素材・照明の変更時は測光値へ合わせ、その後は最大4回/秒で測光しながら滑らかに追従します。カメラ切替のたびに倍率を初期化する方式ではありません。

## GLBの照明

「自動：素材の照明を優先」では、有効なGLB照明やシーン内の照明があれば標準ライトを追加しません。照明がない場合だけ標準ライトを使用します。「素材の照明のみ」は標準ライトを常に外し、「素材＋標準照明」は両方を使います。環境マップは追加しません。

glTFのスポット・ポイントのcd、平行光源のlxをGLTFLoaderのまま扱います。照明強度を一律に683で割る処理は入れていません。

## Blenderモデルの比較プリセット

「今回のBlenderモデルとの比較」のボタンは、会話で提供された次の設定を適用します。

- AgXトーンマッピング、sRGB出力。
- 手動露出倍率は2^0.8÷683、約0.002549。
- 素材に含まれる照明のみ。標準ライトと追加の環境マップは使用しない。

これは今回の比較用設定です。すべてのBlender書出しに使える換算式や、Blenderと同じ見た目を保証する設定ではありません。自動露出の初期値にはこの換算を使いません。

## 制限と診断

透明な背景は測光から除外します。透明物だけのシーンなど、測光対象が足りない場合は直前の値を維持して「測光対象なし」と表示します。HDRターゲットが使えない環境や読出しエラーでは手動値へ戻り、理由をDockへ表示します。

プレビューは本番と同じ処理を使いますが、画角が違えば自動露出の値も変わります。画角に関係なく一定の明るさにしたい場合は、本番を見て「現在値で固定」を使ってください。露出補正だけでは、Blenderとの差に含まれる影・環境光・材質などをすべて再現できません。

測光時には低解像度の追加描画が発生します。初回の同期読出しには短いGPU待ちがあり得ます。OBS本体でのGPU負荷と長時間運転は利用環境で確認してください。
