# 起動とOBSへの登録

対象は0.1.0-rc.3、Windows x64のリリース候補です。実通話とOBS本体での受け入れ試験は未完了です。最初は配信せずにプレビューで確認してください。

## 1. ZIPを展開する

配布ZIPを、書き込み可能なフォルダーへすべて展開します。Bun、Node.js、Pythonの導入は不要です。フォントはOSのものを使います。exeは未署名です。OSの保護機能を無効にする操作は案内していません。

`Start-Demo.cmd`または`ENTAKU-Overlay.exe`を起動すると、デモ用の操作ページが開きます。`Start-Demo.cmd`は起動失敗時にコンソールを残します。開かない場合はコンソールの`Dock:`のURLをブラウザに貼り付けてください。起動したコンソールは開いたままにします。

## 2. デモで動作を確認する

人物のマイクアイコン（「発話 ON」）を押すと縁が緑に光ります。1秒の実発話を満たすと話者候補になりますが、最短ショット維持中や机の拡張中は切替を待ちます。理由はDockに表示します。3人の同時発話が700ms続くとワイドにします。

参加者の「…」メニューから「退出」を選んでも席は残ります。「復帰」は同じ席IDへ戻します。「席予約をリセット」は現在の参加者で配置を作り直す操作です。人数や画像の幅が増えた場合は机を拡げます。単純な退出や画像の縮小では机を縮めません。

## 3. Discordへ接続する

デモをCtrl+Cで終了し、`Start-Live.cmd`を起動します。StreamKit互換認証の説明に同意する場合だけYを選択します。Discord側にStreamKitとして認可画面が出る場合があります。独立して承認されたENTAKUアプリの認証ではありません。

コマンドから起動する場合は次のとおりです。

```powershell
.\ENTAKU-Overlay.exe --live --compat-auth --accept-streamkit-compat
```

音声そのものは受信・記録しません。参加者・発話開始終了の情報だけを扱います。認可を拒否した場合は再認可を繰り返さず、Dockへ状態を表示します。必要なときだけ「再認証・再接続」を押します。

## 4. OBSの二つのページを登録する

OBSのブラウザソースに、Dockの「OBSブラウザソースのURL」を設定します。幅1920、高さ1080を基準にします。透明な背景へ円卓と人物が表示されます。スタジオを追加した場合はその背景も描画します。

OBSのカスタムブラウザドックには、コンソールのDock URLを設定します。表示ページは`http://127.0.0.1:31337/overlay`、操作ページは`http://127.0.0.1:31337/dock`です（ポート変更時は読み替えます）。URL末尾のキーは不要です。以前の版で登録した`#key=...`は削除して構いません。

ソースを再読み込みしたりDockを閉じたりしても、Bun側のDiscord接続・席・カメラ判断は維持します。exeを終了した場合は維持しません。接続復旧時にはBunの状態を再取得します。

## 問題があるとき

`PORT_IN_USE`は別の起動中プロセスとポートが重なっています。勝手に他のプロセスを終了せず、先に起動したENTAKUを終了するか`--port 31338`などを指定します。ポートを変えたらOBSのURLも更新します。

`DATA_PATH_PERMISSION_DENIED`は書き込み可能な場所へ展開し直すか、`--data-dir DIRECTORY`を指定します。設定を消さずに切り分けるには`--safe-mode`を使います。このモードは保存済み設定を書き換えず、メモリ内の状態だけを使います。

`--doctor`はDiscordの認証を行わない診断です。Dockの診断JSONには名前・Discord IDを含めません。以前の版の`data/access-keys.json`は新しい版では使用せず、自動削除もしません。公開Issueへは参加者名や個人情報を含むログを貼らないでください。

```powershell
.\ENTAKU-Overlay.exe --doctor
.\ENTAKU-Overlay.exe --safe-mode --no-open --port 31338
```

終了はCtrl+Cです。アップデート前に終了し、`data/`をバックアップしてからexeを入れ替えます。

## 司会席と新しいDock

参加者の「…」メニューで「司会に指定」または「共同司会に追加」を選びます。司会は奥の丸み、一般参加者は左右の対面列、奇数の余り1人は手前の丸みに配置します。5席・司会1名なら左右2組です。司会変更はワイドで再配置し、以前の机の長さを勝手に縮めません。

右上の外観選択はシステム／ライト／ダークです。スタジオ設定、接続、診断は補助ペインにまとめています。狭いDockでは一覧の下に続きます。人物画像の編集は各参加者メニューから開きます。表示URLと操作URLは引き続きキー不要です。
