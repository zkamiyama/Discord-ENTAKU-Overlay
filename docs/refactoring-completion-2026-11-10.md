# リファクタリングの実装・検証記録

対象は2026-11-10のリファクタリング。Discord・OBS・実GPUを組み合わせた実機検証は利用者が担当する。以下は、その手前の実装、自動試験、配布準備を確認する記録である。

## 今回仕上げた点

以前の作業ツリーに残っていた描画改善を取り込み、席予約が残る退出でも、卓上小物の表示変更で影が更新されるようにした。ライトの影用テクスチャもシーンと一緒に解放する。

OverlayをAvatar、stage-frame、ProgramRendererへ分離した。机と席の補間は純粋関数、単独／分割の描画資源は専用クラスが担当する。カメラの切替直後に人物を向ける順序と、本番の露出除外・深度処理は維持した。

ShotDirectorの候補と絶対期限をshot-transitionへ切り出した。START_PENDING、END_CONFIRMING、END_GRACE等は判定時に設定し、診断文言から逆算しない。旧版との決定的な比較では、32,000ステップの構図・理由・切替期限が一致した。

画像編集はAvatarPreviewがプレビューと非同期ビルドを所有する。画像の所有コピーを使い、編集を閉じたり次の画像へ進んだりしても、古い完了処理が新画面を変更しない。校正画面には本番と同じSSR・GTAO・SSGIを重ねず、形状・机との位置・背面・発話グローの確認に必要な描画を残した。本番の画質既定値は変更していない。

## CIタイムアウトの切り分け

GitHubのca52056ではブラウザ48件成功・3件失敗だった。2コアに制限したローカル環境で対象8件を実行すると、画像編集を含む2件が失敗した。トレースでは、画像編集を開くクリックに約30秒を費やしていた。

校正用プレビューを分離した後は、同じ2コア制限と同じタイムアウトで8件すべて成功した。クリックを強制したり、試験時間を延長したりして通したものではない。これは再現環境で確認した改善であり、あらゆるGPUの性能保証ではない。

## 自動検証

| 検査 | 確認した結果 |
|---|---|
| 型検査・単体／結合 | 242件成功。未使用変数・引数の検査も有効 |
| ブラウザ回帰 | 51件成功。既定の画質、透過、色、深度、影、SSR、DoF、分割、Dock、素材、VC-CHATを検査 |
| 制限環境の再試験 | 2コア制限の対象8件が成功 |
| クリーンな取得 | e280ee0のファイルが試験したソースと一致し、取得し直した環境でも242件成功 |
| 単独起動 | LinuxでPATHを空にし、コピーした実行ファイルだけでHTTPと埋込素材を確認。Discord認可は実行しない |

GitHub CIはWindows・Linuxのチェックとブラウザ2シャードを同じコミットで実行する。GitHub側の最終状態とWindows ZIPは、そのコミットのActions実行結果を確認する。CIの起動だけを成功とは扱わない。

描画計測の12条件では、シーン破棄後の資源数がジオメトリ0、テクスチャ1で一定だった。残る1枚はThree.js 0.187.0の共有DFG_LUT（16×16）と特定した。シーンが所有する影と、Renderer内部で共用する資源を区別し、計測終了後にRendererとコンテキストを閉じる。資源数はGPU使用バイト数ではない。

## 今回採用しない追加仕様

差分配信は時計同期・再接続・補間の契約変更になるため採用しない。自動画質低下も、実GPUでの計測前に配信の見た目を変えないため採用しない。これらを未完成のリファクタリングとして残さず、将来別の機能要求がある場合に検討する。

電源断や強制終了に対する複数ファイルの一括復旧は追加しない。現在の保証は単一ファイルの置換と、捕捉した例外に対する巻戻しである。更新前のdataバックアップは引き続き必要である。署名付き配布、StreamKit互換認証の公式承認、実GPUの速度を保証するものでもない。

## 実機確認への引き渡し

[配布前チェックリスト](release-checklist.md)に環境と確認項目をまとめた。Releaseは公開せず、実機確認後に担当者が手動で下書きを作成できる構成にした。通常のCIにはWindows ZIPとSHA-256が残る。

バージョン表示はRC.15のまま。確認対象はBUILD-INFO.jsonのコミットで区別する。既存の設定や素材を初期化する必要はない。
