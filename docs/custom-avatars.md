# カスタムアバター

Dockで人物の「参加者メニュー」から「画像を調整」を開きます。正面のPNGまたは静止WebPを選び、顔の矩形をドラッグで指定してください。画像全体ではなく顔高0.28mを基準に倍率を計算します。倍率・横位置・縦位置は数値でも調整できます。

## プレビューと適用

上部の3Dプレビューをドラッグすると、OrbitControlsで視点を回して机との関係を確認できます。編集画面を閉じると描画を停止し、GPU資源を解放します。「適用」を押すまでは配信映像を変更しません。別のDock操作で編集revisionが変わった場合は、上書きせず競合を表示します。

「背面画像」を開くと、別の画像と背面用の顔矩形を指定できます。省略時は正面画像を裏から減光して表示します。独立した背面画像も減光します。正面画像を使い回した場合の裏面は鏡像です。正しく描いた背中を表示する場合は背面画像を用意してください。

「撮影範囲」を有効にすると、顔を含む矩形を黄色で指定できます。カメラはこの範囲と名前プレートを画角へ収めます。画像自体を切り抜く機能ではありません。指定を省略すると画像全体を基準にします。

## 向きと発話

人物の正面は席の内向き法線です。カメラが前方にある場合だけY軸±30度まで追従します。後方へ振り向くことや、上下方向のビルボード回転はしません。発話の緑色は実際の音量ではなく、START/STOPと穏やかな強度変化で制御します。

アルファの境界から距離マップを作り、輪郭に沿って発光させます。画像の矩形を発光させる方法ではありません。透過部分の穴も対象です。距離マップは最大1024pxのマスクからWorkerで生成します。机の深度を使うため、机の下の人物部分が手前へ透けないようにしています。

## 席間隔と保存

正面と背面の占有幅を計算し、必要なら席間隔を拡張します。現在は全席を同じ間隔で拡げる方式です。個別の可変幅パッキングではありません。拡張値はセッションに保存し、画像を縮小・解除しても机を自動縮小しません。縮小は席予約リセットで行います。

元画像は内容ハッシュで`data/assets/avatars/`へ、Discord ID・顔矩形・倍率・位置・背面・撮影範囲は`data/avatars.json`へ保存します。最大寸法4096×4096px、20MiB、占有幅2.8mです。アニメーション画像と完全透明な画像は受け入れません。「Discordアイコンへ戻す」でその人物の設定を解除できます。

## 検証

画像形式と寸法、座標変換、距離マップ、保存失敗、編集競合を自動テストしています。ブラウザでは矩形ドラッグ・狭いDock・保存復元・前後画像を確認します。背面の減光は、同じ色の正面・背面を描画した画素の明るさで比較します。OBSの実機表示と実GPUでのフレーム時間は別の受け入れ項目です。

カメラの肩越し遮蔽検査では、正面・背面の全画像範囲を使います。「撮影範囲」でカメラの構図を狭めても、他の人物を隠す範囲は小さくなりません。透明な余白も含む保守的な近似なので、必要なら元画像の余白を減らしてください。
