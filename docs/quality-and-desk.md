# 画質と机

Dockの「画質と卓上」で、影と画面効果を選びます。自動露出は引き続き既定で有効です。人物画像、Discordアイコン、発話グロー、名札の印刷面には露出・AO・反射の色補正をかけません。机が人物の手前にあるときの遮蔽は維持します。

## 画質を選ぶ

| 項目 | 用途と制限 |
|---|---|
| ソフトシャドウ | PCFで影の輪郭をなめらかにする。標準は1024px・最大2灯 |
| GTAO | 机や小物の接地感と隙間の陰影を補う。距離と強さを変更可能 |
| SSR | 画面内にある物体を滑らかな材質に反射する。画面外の物体は反射しない |
| MSAA | 形状の端を複数サンプルで描く。標準4x、対応GPUでは8xを選択可能 |
| 描画解像度 | 100・150・200%。高解像度で描いて縮小し、細い形状と人物の輪郭をなめらかにする |
| FXAA | 追加の画面平滑化。MSAAや高解像度描画の代わりではない |
| SSGI（実験的） | 画面内の表面からの1回の拡散反射を近似する。強さと距離を変更可能。初期値は無効 |
| 効果の解像度 | AO・反射・間接光の計算を50・75・100%から選ぶ。低いほど負荷を抑えられる |

「軽量」は影と画面効果を無効にし、「標準」はソフトシャドウとMSAA 4xを使います。「高画質」は影2048px、MSAA 4x、描画解像度150%、GTAO・SSRを使います。SSGIはどのプリセットでも初期状態では無効です。プリセットを変えても、自動露出と名札の配色は変えません。

影を生成するライトは平行光源とスポットライトから最大1・2・4灯を選びます。ライトの発光自体をその灯数に制限する意味ではありません。全6方向の影が必要なポイントライトは、影の生成対象外です。

SSRは基本的なスクリーンスペース反射です。AMD FidelityFX SSSRではありません。SSGIは別の実験オプションです。人物は色を保持する別の描画レイヤーにあり、SSRの映り込み、AOやSSGIの生成には使いません。

使えないGPUや処理エラーでは効果を無効にして直接描画へ戻し、Dockに状態を出します。実際のOBSでのフレームレートは素材・GPU・画面サイズによって変わります。反射から順に切り、影の解像度や灯数を下げて負荷を調整してください。

## 机は司会側を固定して伸ばす

最初の在席配置の奥側を保存し、人数が増えると手前へ伸ばします。机の後ろへ置いたカスタムスタジオは動かしません。退出では机を縮めず、復帰は予約した論理席へ戻ります。

旧版のセッションには、その既存配置を基準として設定します。「席予約をリセット」は現在の参加者で基準も作り直す操作です。司会人数の変更による席の組み替えと、単なる増席による伸長は別です。

手前側や左右にある壁を自動で移動・削除する機能ではありません。机が大きくなる方向の空間は確保してください。

## 卓上の見た目

生成するモニターとコップはなくしました。マイクと名札の設置面は、1〜32席・司会1〜2名で天板内へ収まるようにしています。読み込んだGLB自体に含まれる小物は削除しません。

名札は台形断面で、前後とも正しい向きの名前を表示します。左右の余白を小さくした太字を使います。白地・青文字が既定で、参考写真のような青地・白文字にも変更できます。フォントはOSのものを使い、ファイルは同梱しません。

天板には木目、微細な凹凸、薄いクリアコートを設定しました。マイクは重みのある台座、曲がったネック、カプセル状のヘッドとグリルを持ちます。

## RC.6の修正

SSRは反射だけを元のHDR背景へ合成します。専用の深度を24bitにし、反射しない画素の出力を初期化しました。ぼかし後も反射対象のマスクを適用し、背景を低精度の別描画で置き換えないようにしました。モデル自体に重複面がある場合まで解消する保証ではありません。

MSAAは対応するサンプル数をGPUへ問い合わせます。8x非対応なら4xなどへ下げ、描画バッファは4096×2304以内にします。150%は約2.25倍、200%は約4倍の画素数になるため、負荷に応じて選んでください。

SSGIは1画素につき8方向・最大16ステップで、画面内に見える表面の光を拾います。Three.jsの深度・法線再構成とPoissonデノイズを使います。画面外、裏面、複数回反射は再現しません。時間方向の蓄積を使わないので、カット前の光は残りませんが、ノイズや画角による変化が出る場合があります。AOを暗くするだけの効果ではありません。

カメラ切替後の人物の向きは即時反映します。Y軸±30度の制限はそのままで、遅い首振りだけを削除しました。カメラのMOVE、机の伸長、発話グローの立ち上がりは引き続きアニメーションします。
