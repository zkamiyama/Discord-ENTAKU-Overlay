# RC.7の追加描画確認

2026-11-09。113件の単体・結合テストと27件のブラウザテストが成功した後、艶を強めた天板を実際に描画して確認した。

SSRのON時に天板の縁が黒くなるケースを検出した。反射成分を合成する前に非有限値を除外し、負の色成分をゼロに制限して、正常な反射だけを加えるよう修正した。同じ構図と固定露出でSSRをON/OFFする回帰試験を追加し、元の明るい面が黒く変わる画素が0であることを確認した。反射そのものを消す修正ではない。

この修正後に型検査・113件の単体/結合テストと、ポストエフェクト関連の5件のブラウザテストが成功した。全ブラウザ試験は追加分を含めて28件で、配布対象コミットのCIで実行する。ユーザーのカスタムGLBとOBS実GPUの確認とは区別する。
